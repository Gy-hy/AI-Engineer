    Network（★★★★★）¶

    目标：理解 Web 通信原理，能够独立设计、开发、部署 AI Web 服务，掌握现代 AI 产品常用的网络协议与认证机制。

    1. HTTP（★★★★★）¶

    必学内容¶

    HTTP 基础¶

    理解：

    • Client / Server
    • Request / Response
    • URL
    • URI
    • Header
    • Body
    • Query Parameter
    • Path Parameter
    • Cookie

    HTTP 方法¶

    掌握：

    • GET
    • POST
    • PUT
    • PATCH
    • DELETE
    • OPTIONS
    • HEAD

    HTTP 状态码¶

    必须熟练：

    • 200
    • 201
    • 204
    • 301
    • 302
    • 304
    • 400
    • 401
    • 403
    • 404
    • 405
    • 409
    • 422
    • 429
    • 500
    • 502
    • 503
    • 504

    理解：

    每种状态码的使用场景。

    HTTP Header¶

    必须：

    • Authorization
    • Content-Type
    • Accept
    • User-Agent
    • Host
    • Cookie
    • Set-Cookie
    • Cache-Control
    • Origin
    • Referer

    HTTP 缓存¶

    理解：

    • ETag
    • Last-Modified
    • Cache-Control
    • Expires

    必做项目¶

    使用 FastAPI 实现完整 REST API。

    要求：

    • 正确使用 HTTP Method
    • 正确返回 Status Code
    • Header 完整
    • 错误处理规范

    2. HTTPS（★★★★★）¶

    必学内容¶

    理解：

    • TLS
    • SSL
    • Certificate
    • Public Key
    • Private Key
    • CA
    • Handshake

    掌握：

    • HTTPS 配置
    • Let's Encrypt
    • 自签名证书

    理解：

    为什么 HTTPS 比 HTTP 安全。

    必做项目¶

    使用 Nginx：

    部署 HTTPS。

    要求：

    浏览器访问：

    https://

    无证书错误。

    3. REST API（★★★★★）¶

    必学内容¶

    理解：

    RESTful

    掌握：

    • Resource
    • URI Design
    • CRUD
    • Versioning
    • Pagination
    • Filtering
    • Sorting
    • Error Response

    API 规范：

    • OpenAPI
    • Swagger
    • JSON Response

    必做项目¶

    设计：

    AI Chat API。

    要求：

    符合 RESTful 规范。

    4. WebSocket（★★★★★）¶

    必学内容¶

    理解：

    为什么需要：

    WebSocket。

    掌握：

    • Handshake
    • Connection
    • Message
    • Close
    • Ping
    • Pong

    应用：

    • Chat
    • 实时通知
    • Agent

    FastAPI：

    WebSocket

    必做项目¶

    实现：

    实时聊天室。

    支持：

    • 多用户
    • 广播
    • 在线人数
    • 心跳检测

    5. SSE（★★★★★）¶

    必学内容¶

    理解：

    Server-Sent Events

    与：

    WebSocket

    区别。

    掌握：

    • Event Stream
    • Streaming Response
    • Keep Alive

    应用：

    AI：

    • ChatGPT
    • Claude
    • DeepSeek

    流式输出。

    必做项目¶

    实现：

    LLM Streaming API。

    要求：

    浏览器实时显示：

    Token 输出。

    6. JWT（★★★★★）¶

    必学内容¶

    理解：

    JWT 原理。

    掌握：

    • Header
    • Payload
    • Signature
    • Access Token
    • Refresh Token
    • Expiration

    安全：

    • Token Storage
    • Refresh
    • Logout

    FastAPI：

    JWT 登录。

    必做项目¶

    实现：

    用户系统。

    要求：

    • 注册
    • 登录
    • Refresh Token
    • 权限验证

    7. OAuth（★★★★★）¶

    必学内容¶

    理解：

    OAuth2

    OIDC（了解）

    掌握：

    • Authorization Code
    • Client
    • Resource Server
    • Access Token
    • Refresh Token

    第三方登录：

    • GitHub
    • Google

    理解：

    OAuth 与 JWT 的区别。

    必做项目¶

    实现：

    GitHub OAuth 登录。

    8. Nginx（★★★★★）¶

    必学内容¶

    理解：

    Nginx 工作原理。

    掌握：

    • Reverse Proxy
    • Load Balance
    • SSL
    • Static File
    • Compression
    • Cache
    • Upstream

    配置：

    • server
    • location
    • proxy_pass
    • rewrite

    日志：

    • access.log
    • error.log

    必做项目¶

    部署：

    FastAPI + Nginx。

    要求：

    支持：

    • HTTPS
    • Reverse Proxy
    • Static File
    • Gzip

    9. API 安全（★★★★★）¶

    必学内容¶

    掌握：

    • CORS
    • CSRF
    • XSS（了解）
    • SQL Injection（了解）
    • Rate Limit
    • API Key

    理解：

    现代 API 安全。

    必做项目¶

    为 AI API：

    增加：

    • CORS
    • JWT
    • Rate Limit

    10. 网络调试（★★★★★）¶

    必学内容¶

    掌握：

    • curl
    • wget
    • Postman
    • Bruno（推荐）
    • httpie

    抓包：

    • Chrome DevTools
    • Wireshark（了解）

    理解：

    请求全过程。

    必做项目¶

    调试：

    一个完整 AI API。

    要求：

    分析：

    • Header
    • Cookie
    • Token
    • Response

    11. 高性能网络（★★★★☆）¶

    必学内容¶

    了解：

    • HTTP/2
    • HTTP/3
    • QUIC
    • Keep Alive
    • Compression
    • Connection Pool

    AI：

    Streaming

    Latency

    Connection Reuse

    必做项目¶

    优化：

    LLM Streaming。

    要求：

    降低：

    首 Token 延迟。

    Network 综合毕业项目（★★★★★）¶

    AI Web Service

    实现一个生产级 AI Web 服务。

    要求¶

    • RESTful API 设计规范
    • OpenAPI 自动文档
    • JWT 用户认证
    • GitHub OAuth 登录
    • WebSocket 实时聊天室
    • SSE 实现 LLM Token Streaming
    • Nginx 反向代理与 HTTPS 部署
    • 支持静态资源与 Gzip 压缩
    • 配置 CORS、Rate Limit、统一错误处理
    • 使用 curl、Bruno 或 Postman 完成 API 测试
    • 编写完整 API 文档

    毕业标准： 能够独立设计、开发并部署一个现代 AI Web 服务，熟练掌握 HTTP、WebSocket、SSE、JWT、OAuth、Nginx 等核心网络技术，为后续 Backend、LLM、Agent 和 AI 产品开发打下坚实基础。
