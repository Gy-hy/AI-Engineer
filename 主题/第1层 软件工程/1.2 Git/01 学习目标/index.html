    Git 综合毕业项目（★★★★★）¶

    Open Source Workflow Simulation

    模拟一个真实的开源项目开发流程。

    要求¶

    • 使用 Git Flow 或 Fork Workflow 管理开发
    • 至少维护 main、develop、多个 feature/*、release/*、hotfix/* 分支
    • 完成不少于 30 次规范 Commit（遵循 Conventional Commits）
    • 使用 Interactive Rebase 整理历史
    • 创建并管理多个 Tag 与 GitHub Release
    • 配置 GitHub Actions，实现自动测试与构建
    • 至少解决 3 次模拟冲突（Merge、Rebase、Cherry-pick）
    • 提交至少 1 个开源项目 PR（最终成功 Merge 为最佳，未 Merge 但 Review 完整也可）
    • 编写完整的 README、CHANGELOG、CONTRIBUTING、Issue Template、PR Template

    毕业标准： 能够独立管理个人项目，熟练参与团队协作，并具备参与开源社区开发的 Git 工作流能力。后续所有项目都应严格按照这一套 Git 规范执行。
