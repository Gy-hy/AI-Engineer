    Docker 综合毕业项目（★★★★★）¶

    AI Development Stack

    搭建一套完整的 AI 开发与部署环境。

    要求¶

    • 编写生产级 Dockerfile（Multi-stage、非 root、Health Check）
    • 使用 Docker Compose 编排整个 AI 系统
    • 包含 FastAPI、PostgreSQL、Redis、Qdrant、Nginx、vLLM（或 Ollama）
    • 配置 Network，实现容器间通信
    • 配置 Volume，实现数据库、日志、模型缓存持久化
    • 支持 GPU 推理（NVIDIA Container Toolkit）
    • 将镜像发布到 Docker Hub 或 GHCR
    • 配置 GitHub Actions，自动 Build、Test、Push Image
    • 编写完整部署文档（README）

    毕业标准： 任何人在一台安装好 Docker 的 Linux 服务器上执行：

    git clone <your-project>
cd <your-project>
docker compose up -d

    即可完成 AI 服务 + 数据库 + 向量数据库 + 模型推理服务 的完整部署，无需任何手工配置。这将成为你后续所有 AI 项目的标准部署模板。
