# 11. AI Product Architecture（★★★★★）

## 必学内容

理解：

一个现代 AI 产品通常包含：

```text
用户
   │
   ▼
Chat UI
   │
   ▼
FastAPI Backend
   │
   ├── LLM Gateway
   ├── RAG
   ├── Agent
   ├── Memory
   ├── MCP
   ├── Plugin
   ├── PostgreSQL
   ├── Redis
   ├── Qdrant
   └── Object Storage
```

理解各模块之间的数据流与职责边界。

---

## 必做项目

绘制：

完整 AI 产品架构图。

并实现其中各模块的协作。

# AI Product 综合毕业项目（★★★★★）

> **AI Workspace Platform**

## 功能要求

* ChatGPT 风格聊天
* 企业知识库（RAG）
* 多 Workspace
* 长期 Memory
* Plugin 系统
* 多用户与团队协作
* RBAC 权限控制
* WebSocket 实时同步
* 文档版本管理
* 优秀 AI UX（Streaming、Citation、Markdown、代码高亮）
* FastAPI + Docker Compose 一键部署

---

## 毕业标准（★★★★★）

完成该项目后，你应达到以下能力：

* 能独立设计并开发一个完整的 AI 产品，而不仅是实现某个 AI 功能。
* 能构建支持聊天、知识库、Memory、Plugin、多用户协作的产品架构。
* 能从产品、工程和用户体验三个维度思考 AI 应用设计。
* 具备开发 **ChatGPT、Claude、Notion AI、Cursor、OpenWebUI** 等同类型 AI 产品的能力。
