# CI/CD 综合毕业项目（★★★★★）

> **AI Delivery Pipeline**

## 功能要求

* GitHub Actions 或 GitLab CI
* 自动 Lint / Test / Build
* Docker 镜像构建与推送
* 测试环境自动部署
* 生产环境手动审批
* 回滚机制
* Evaluation in CI
* 环境与密钥隔离

---

## 毕业标准（★★★★★）

完成该项目后，你应达到以下能力：

* 能为 AI 项目建立完整的自动化交付流程。
* 能将代码、Prompt、模型配置、评测结果纳入统一发布治理。
* 能降低“改一个 Prompt 就直接影响生产”的工程风险。

---

## **学习优先级（建议）**

| 技术             | 优先级   | 必须掌握程度 |
| -------------- | ----- | -----: |
| GitHub Actions | ⭐⭐⭐⭐⭐ |     精通 |
| Docker Registry| ⭐⭐⭐⭐⭐ |     精通 |
| Deploy         | ⭐⭐⭐⭐⭐ |     精通 |
| AI 专项流程         | ⭐⭐⭐⭐⭐ |     精通 |
| 质量门禁            | ⭐⭐⭐⭐☆ |     熟练 |
| 环境与密钥管理         | ⭐⭐⭐⭐☆ |     熟练 |
| Release        | ⭐⭐⭐⭐☆ |     熟练 |
| GitLab CI      | ⭐⭐⭐☆☆ |     熟悉 |

> **建议：** 很多 AI 项目死在“没有交付纪律”。代码能跑、模型能调、Prompt 能改，不代表系统能稳定演进。你需要把 Evaluation、版本、部署、回滚都纳入同一条流水线，才算真正具备生产级交付能力。
