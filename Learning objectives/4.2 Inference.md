# Inference 综合毕业项目（★★★★★）

> **Enterprise LLM Gateway**

## 功能要求

* vLLM 部署开源模型
* LiteLLM 统一模型访问
* 支持 OpenAI 兼容接口
* 模型路由与 Fallback
* Prompt Cache
* Rate Limit 与访问控制
* 性能压测与成本统计
* Docker Compose 部署

---

## 毕业标准（★★★★★）

完成该项目后，你应达到以下能力：

* 能独立部署开源模型推理服务，并理解其性能瓶颈。
* 能设计企业内部的 Model Gateway，而不是让应用直接绑定某个 Provider。
* 能从吞吐、延迟、成本、稳定性四个维度优化推理系统。
