# 5.3 Source Code Reading（★★★★★）

> **目标：建立系统化源码阅读能力，通过阅读优秀 AI 项目的真实实现，快速提升架构感、工程判断和技术深度。**

---

# 1. 为什么必须读源码（★★★★★）

## 必学内容

理解：

* 文档告诉你“能做什么”
* 源码告诉你“实际上是怎么做的”

理解：

为什么高级工程师的成长速度，往往取决于源码阅读能力。

---

## 必做项目

写一篇：

《为什么 AI System Engineer 必须读源码》的个人总结。

---

# 2. 阅读方法（★★★★★）

## 必学内容

掌握：

* 先看 README / Docs
* 再看入口
* 再看主链路
* 再看关键抽象
* 最后看边界与细节

理解：

源码阅读不是从第一行看到最后一行。

---

## 必做项目

为自己制定：

源码阅读模板。

---

# Source Code Reading 综合毕业项目（★★★★★）

> **AI OSS Reading Portfolio**

## 功能要求

* 至少阅读 5 个核心项目
* 每个项目输出结构化笔记
* 至少 2 个项目绘制执行流程图
* 至少 1 个项目写出架构拆解文章
* 建立长期源码阅读清单

---

## 毕业标准（★★★★★）

完成该项目后，你应达到以下能力：

* 能高效进入陌生代码库，而不是一看到大项目就退缩。
* 能从优秀开源项目中提取架构模式和工程经验。
* 能通过持续源码阅读，加速自己在 AI 工程领域的成长。
