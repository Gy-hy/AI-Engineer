# Python 综合毕业项目（★★★★★）

> **Python Developer Toolkit**

要求整合前面所有知识，实现一个可发布、可部署、可测试的完整工程。

## 功能要求

* CLI（click 或 argparse）
* 完整类型标注（typing）
* 面向对象设计（OOP）
* asyncio 并发任务
* 自定义装饰器
* 自定义 Context Manager
* Generator 数据流
* 企业级 Logging
* 配置管理（`.env` / `pydantic-settings`）
* 单元测试（覆盖率 ≥90%）
* 打包为 Python Package（`pyproject.toml`）
* GitHub Actions 自动测试
* Docker 镜像构建
* 完整 README 与使用文档

> **毕业标准：** 任何人执行 `git clone` → `uv sync` → `pytest` → `uv run` 即可运行整个项目。这意味着你已经具备了进入下一阶段（Backend Engineering）的 Python 工程能力。
