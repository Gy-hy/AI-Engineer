# RAG 综合毕业项目（★★★★★）

> **Enterprise RAG Platform**

## 功能要求

* 文档上传（PDF、Word、Markdown、HTML）
* 自动 Chunk、Embedding、入库
* Qdrant 向量数据库
* Elasticsearch Hybrid Search
* Rerank 优化检索结果
* 支持 Citation（文件名、页码、Chunk）
* RAG Evaluation（Ragas / DeepEval）
* GraphRAG（实体关系检索）
* Agentic RAG（动态检索与规划）
* FastAPI + Docker Compose 一键部署

---

## 毕业标准（★★★★★）

完成该项目后，你应达到以下能力：

* 能独立设计和优化企业级 RAG 系统。
* 能根据业务选择合适的 Chunk、Embedding、Retriever、Rerank 策略。
* 能实现 Hybrid Search、Citation、Evaluation 等生产级能力。
* 能构建支持 **GraphRAG、Agentic RAG、Knowledge Graph** 的高级知识系统，为 AI 搜索、智能问答、Agent 和 AI Companion 提供可靠的知识基础。

---

## **学习优先级（建议）**

| 技术                      | 优先级   |   必须掌握程度 |
| ----------------------- | ----- | -------: |
| Embedding               | ⭐⭐⭐⭐⭐ |       精通 |
| Chunk                   | ⭐⭐⭐⭐⭐ |       精通 |
| Retriever               | ⭐⭐⭐⭐⭐ |       精通 |
| Vector Database（Qdrant） | ⭐⭐⭐⭐⭐ |       精通 |
| Hybrid Search           | ⭐⭐⭐⭐⭐ |       精通 |
| Rerank                  | ⭐⭐⭐⭐⭐ |       精通 |
| Citation                | ⭐⭐⭐⭐☆ |       熟练 |
| Evaluation              | ⭐⭐⭐⭐☆ |       熟练 |
| Agentic RAG             | ⭐⭐⭐⭐☆ |       熟练 |
| Knowledge Graph         | ⭐⭐⭐⭐☆ |       熟练 |
| GraphRAG                | ⭐⭐⭐☆☆ | 熟悉（按需深入） |

> **建议：** 目前企业级 RAG 的主流路线是 **Embedding → Chunk → Retriever → Hybrid Search → Rerank → Evaluation**，这是必须精通的核心链路。**GraphRAG** 仍属于较新的方向，适合处理复杂关系推理；**Knowledge Graph** 更偏向结构化知识建模，两者结合效果最佳，但不必一开始投入过多精力。先完成一个稳定、高质量的 RAG 平台，再逐步演进到 **Agentic RAG** 和 **GraphRAG**。
