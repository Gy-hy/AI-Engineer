# Search 综合毕业项目（★★★★★）

> **AI Search Service**

## 功能要求

* Docker 部署 Elasticsearch（或 OpenSearch）
* 建立全文索引
* 支持中文与英文搜索
* 实现 Query DSL 检索
* 支持高亮、分页、排序、过滤
* 与 RAG 集成，实现 Hybrid Search
* FastAPI 提供统一搜索 API

---

## 学习优先级（建议）

| 技术                | 优先级   | 必须掌握程度 |
| ----------------- | ----- | -----: |
| 全文检索原理（倒排索引、BM25） | ⭐⭐⭐⭐⭐ |     精通 |
| Elasticsearch     | ⭐⭐⭐⭐⭐ |     熟练 |
| OpenSearch        | ⭐⭐⭐☆☆ |     熟悉 |

> **建议：** 对 AI System Engineer 来说，重点不是熟练掌握两个产品，而是理解**全文检索的原理**以及它与**向量数据库（Qdrant、Milvus 等）**如何协同工作。实际项目中通常选择 **Elasticsearch 或 OpenSearch 其中一种**即可，后续在 RAG 阶段再深入学习 **Hybrid Search** 和 **Rerank**。
