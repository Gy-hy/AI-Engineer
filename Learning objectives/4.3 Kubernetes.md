# 4.3 Kubernetes（★★★★★）

> **目标：掌握 AI 服务在 Kubernetes 上的部署与运维方法，能够将推理服务、网关、后台服务和监控系统部署到生产环境。**

---

# 1. Kubernetes 基础（★★★★★）

## 必学内容

掌握：

* Cluster
* Node
* Namespace
* ConfigMap
* Secret

理解：

为什么现代 AI 基础设施通常以 Kubernetes 为默认平台。

---

## 必做项目

搭建：

本地或测试 Kubernetes 环境。

部署：

一个基础 Web 服务。

---

# 2. Pod（★★★★★）

## 必学内容

掌握：

* Pod 生命周期
* Volume
* Environment Variable
* Resource Request / Limit

理解：

Pod 是最小部署单元，但不是最终架构边界。

---

## 必做项目

部署：

一个带环境变量和持久化卷的服务。

---

# 3. Deployment（★★★★★）

## 必学内容

掌握：

* Replica
* Rolling Update
* Rollback
* Health Check

理解：

为什么无状态服务适合用 Deployment 管理。

---

## 必做项目

将：

AI Gateway 或 FastAPI 服务

部署为：

Deployment。

---

# 4. Service（★★★★★）

## 必学内容

掌握：

* ClusterIP
* NodePort
* LoadBalancer
* Service Discovery

理解：

集群内部通信与外部访问的区别。

---

## 必做项目

配置：

多个服务之间的集群内访问。

---

# 5. Ingress（★★★★★）

## 必学内容

掌握：

* Ingress
* Domain Routing
* TLS
* Reverse Proxy

理解：

为什么生产服务通常不会直接暴露 Pod 或 Service。

---

## 必做项目

配置：

基于域名的 HTTP 入口。

支持：

HTTPS。

---

# 6. Helm（★★★★★）

## 必学内容

掌握：

* Chart
* Values
* Template
* Release

理解：

为什么 Helm 是 Kubernetes 的事实标准部署方式。

---

## 必做项目

为你的 AI 服务编写：

Helm Chart。

---

# 7. Autoscaling（★★★★☆）

## 必学内容

掌握：

* HPA
* CPU / Memory Metrics
* 自定义指标（了解）

理解：

为什么 AI 服务的扩缩容比普通 Web 服务更复杂。

---

## 必做项目

实现：

基础自动扩缩容。

观察：

负载变化下的副本数变化。

---

# 8. GPU 调度（★★★★★）

## 必学内容

理解：

* GPU Node
* Device Plugin
* Node Selector
* Taint / Toleration

理解：

为什么 GPU 工作负载调度需要额外配置。

---

## 必做项目

部署：

一个 GPU 推理服务到 Kubernetes。

---

# 9. 配置与发布（★★★★★）

## 必学内容

掌握：

* 环境隔离
* Secret 管理
* 镜像版本管理
* 灰度发布（了解）

理解：

生产环境发布为什么需要规范化。

---

## 必做项目

建立：

测试环境与生产环境两套部署配置。

---

# Kubernetes 综合毕业项目（★★★★★）

> **AI Platform on Kubernetes**

## 功能要求

* AI Gateway 部署
* 推理服务部署
* FastAPI Backend 部署
* Ingress + HTTPS
* Helm Chart
* 基础自动扩缩容
* 日志与监控接入
* 测试环境 / 生产环境配置分离

---

## 毕业标准（★★★★★）

完成该项目后，你应达到以下能力：

* 能把 AI 服务部署到 Kubernetes，而不是只会本地 Docker Compose。
* 能理解 Pod、Deployment、Service、Ingress、Helm 在生产系统中的职责。
* 能为 AI Gateway、推理服务和后台服务设计可部署、可回滚、可扩展的集群方案。

---

## **学习优先级（建议）**

| 技术          | 优先级   | 必须掌握程度 |
| ----------- | ----- | -----: |
| Deployment  | ⭐⭐⭐⭐⭐ |     精通 |
| Service     | ⭐⭐⭐⭐⭐ |     精通 |
| Ingress     | ⭐⭐⭐⭐⭐ |     精通 |
| Helm        | ⭐⭐⭐⭐⭐ |     精通 |
| Pod         | ⭐⭐⭐⭐☆ |     熟练 |
| GPU 调度       | ⭐⭐⭐⭐☆ |     熟练 |
| 配置与发布       | ⭐⭐⭐⭐☆ |     熟练 |
| Autoscaling | ⭐⭐⭐☆☆ |     熟悉 |

> **建议：** Kubernetes 不要求你一开始就成为平台专家，但至少要达到“能独立部署 AI 服务并排查基本问题”的水平。对 AI System Engineer 来说，关键不是背 YAML，而是知道怎样把推理服务、网关、监控、配置、发布流程组合成一个可运行系统。
