# Linux 综合毕业项目（★★★★★）

> **Linux AI Server**

搭建一台完整的 AI 开发服务器。

## 要求

* 使用 Ubuntu Server（推荐）或其他主流发行版
* SSH 远程管理（免密登录）
* tmux 管理所有开发会话
* 使用 systemd 托管 FastAPI 服务，支持开机自启
* 使用 journalctl 排查和查看服务日志
* 编写 Shell 脚本完成一键部署
* 配置 Python（uv）、Git、Docker、Nginx 等开发环境
* 使用 grep、sed、awk 实现日志分析脚本
* 配置合理的用户、权限和 sudo 策略
* 能够使用 Linux 工具定位 CPU、内存、磁盘和网络问题
* 实现自动备份（rsync + tar）与恢复
* 编写完整部署文档（README）

> **毕业标准：** 给你一台全新的 Linux 服务器，你可以在 **30 分钟内** 完成开发环境搭建、项目部署、服务启动、日志排查和基础运维，能够独立支撑后续所有 AI 项目的开发与部署。
