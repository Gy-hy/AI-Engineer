# 5.2 Open Source（★★★★★）

> **目标：掌握开源协作方式，能够高质量参与、维护和推动 AI 相关开源项目，建立可见的工程影响力。**

---

# 1. GitHub 基础（★★★★★）

## 必学内容

掌握：

* Repository
* Branch
* Fork
* Star
* Watch

理解：

为什么 AI 工程领域的第一手知识大量存在于 GitHub。

---

## 必做项目

系统整理：

你关注的 AI 开源项目清单。

分类：

* Framework
* Infra
* Product
* Tooling

---

# 2. Issue（★★★★★）

## 必学内容

掌握：

* Bug Report
* Feature Request
* Reproduction
* Discussion

理解：

高质量 Issue 是工程沟通能力的一部分。

---

## 必做项目

在一个开源项目中：

提交高质量 Issue。

要求：

可复现、可定位、表达清晰。

---

# 3. PR（★★★★★）

## 必学内容

掌握：

* Pull Request
* Commit Hygiene
* Review
* Change Scope

理解：

为什么很多人会写代码，但不会提交容易被接受的 PR。

---

## 必做项目

向一个开源项目：

提交至少一个 PR。

---

# 4. Release（★★★★☆）

## 必学内容

理解：

* Semantic Versioning
* Tag
* Changelog
* Breaking Change

理解：

为什么项目成熟后，发布管理就是维护成本控制。

---

## 必做项目

为你自己的项目建立：

版本发布规范。

---

# 5. Roadmap（★★★★☆）

## 必学内容

理解：

* Milestone
* Priority
* Scope
* Community Feedback

理解：

为什么优秀开源项目通常有清晰路线图，而不是随意堆功能。

---

## 必做项目

为你的 AI 项目写出：

一版公开 Roadmap。

---

# 6. Docs（★★★★★）

## 必学内容

掌握：

* README
* Quick Start
* API 文档
* 架构文档
* FAQ

理解：

为什么文档质量直接决定开源项目的可用性。

---

## 必做项目

重写：

一个你自己的项目 README。

要求：

能让新用户 10 分钟内跑起来。

---

# 7. Community（★★★★☆）

## 必学内容

理解：

* Maintainer
* Contributor
* Discussion
* Community Norm

理解：

开源不仅是代码协作，也是一种持续公共沟通。

---

## 必做项目

参与：

至少一个开源项目的 Discussion 或 Review。

---

# 8. 维护视角（★★★★★）

## 必学内容

掌握：

* Scope Control
* Backward Compatibility
* Review 标准
* 用户反馈处理

理解：

“做项目的人”和“维护项目的人”思维完全不同。

---

## 必做项目

以 Maintainer 视角：

为自己的 AI 项目制定贡献规范。

---

# Open Source 综合毕业项目（★★★★★）

> **Open Source AI Project Launch**

## 功能要求

* 公开一个 AI 相关项目
* 完整 README 与文档
* Roadmap
* Issue Template / PR Template（可选）
* 至少一次版本发布
* 至少一次外部协作或贡献记录

---

## 毕业标准（★★★★★）

完成该项目后，你应达到以下能力：

* 能高质量参与开源协作，而不只是“把代码传到 GitHub”。
* 能把自己的项目整理成可被别人使用、理解、贡献的形态。
* 能通过开源建立持续可见的工程积累。

---

## **学习优先级（建议）**

| 技术          | 优先级   | 必须掌握程度 |
| ----------- | ----- | -----: |
| GitHub      | ⭐⭐⭐⭐⭐ |     精通 |
| Issue       | ⭐⭐⭐⭐⭐ |     精通 |
| PR          | ⭐⭐⭐⭐⭐ |     精通 |
| Docs        | ⭐⭐⭐⭐⭐ |     精通 |
| 维护视角        | ⭐⭐⭐⭐☆ |     熟练 |
| Release     | ⭐⭐⭐⭐☆ |     熟练 |
| Roadmap     | ⭐⭐⭐⭐☆ |     熟练 |
| Community   | ⭐⭐⭐☆☆ |     熟悉 |

> **建议：** 开源不是锦上添花，而是 AI 工程师成长速度的放大器。你能不能看懂趋势、吸收最佳实践、建立个人影响力，很大程度上都取决于你是否真正进入开源协作现场。
