# 3.6 Evaluation（★★★★★）

> **目标：掌握 AI 系统评估体系，能够持续评估、监控和优化 LLM、RAG、Agent，构建可迭代、可观测的生产级 AI 系统。**

---

# 1. Prompt Evaluation（★★★★★）

## 必学内容

掌握：

* Golden Dataset
* Prompt Version
* Regression Test
* LLM-as-a-Judge
* 自动评分
* 人工评估

理解：

为什么 Prompt 需要持续评估。

---

## 必做项目

建立：

Prompt Evaluation Pipeline。

支持：

* Prompt 对比
* 自动评分
* 历史版本管理

# Evaluation 综合毕业项目（★★★★★）

> **AI Evaluation Platform**

## 功能要求

* Prompt 自动评测
* RAG 自动评测
* Agent 自动评测
* Golden Dataset 管理
* Benchmark 对比
* A/B Test
* Langfuse Tracing
* AI Observability Dashboard
* CI/CD 自动评测

---

## 毕业标准（★★★★★）

完成该项目后，你应达到以下能力：

* 能持续评估 Prompt、RAG、Agent 的质量，而不是依赖人工测试。
* 能建立企业级 Benchmark 和 Golden Dataset，保障模型升级后的稳定性。
* 能通过 Tracing 和 Observability 快速定位 AI 系统问题，并持续优化成本、延迟和效果。
* 能构建一套完整的 AI Evaluation 平台，为生产环境提供可靠的质量保障。

---
