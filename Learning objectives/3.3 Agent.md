# Agent 综合毕业项目（★★★★★）

> **AI Agent Platform**

## 功能要求

* Planning + Reflection
* Long-term Memory
* Workflow 编排
* Task Center
* State 持久化
* Scheduler 定时执行
* Tool Executor
* Browser Agent（Playwright）
* Deep Research
* Coding Agent
* Multi-Agent 协作
* A2A 通信
* LangGraph 实现 Agent Workflow
* Docker Compose 一键部署

---

## 毕业标准（★★★★★）

完成该项目后，你应达到以下能力：

* 能独立设计和开发生产级 AI Agent。
* 能实现 Planning、Reflection、Memory、Workflow、State 等核心能力。
* 能构建 Browser Agent、Coding Agent、Deep Research Agent 等复杂智能体。
* 能开发支持 Multi-Agent 与 A2A 协作的 Agent 平台，为 AI Assistant、AI Companion、自动化办公等场景提供完整解决方案。
