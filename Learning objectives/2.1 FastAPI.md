> **AI Backend Service**

开发一个可直接作为 AI 产品后端的生产级服务。

## 功能要求

### 用户系统

* 注册
* 登录
* JWT
* RBAC 权限控制

---

### AI Chat

* Chat API
* SSE Streaming

* 聊天历史

---

### 知识库

* 文件上传（PDF、DOCX、TXT、Markdown）
* Background Task 自动解析
* OCR（预留）
* Embedding（预留）

---

### 数据层

* PostgreSQL
* Redis

* Alembic Migration

---

### 工程能力

* Dependency Injection
* Middleware
* 生命周期管理

* 统一异常处理

* Health Check

---

### 部署

* Docker
* Docker Compose
* Nginx
* GitHub Actions 自动测试

---

## 毕业标准（★★★★★）

完成该项目后，你应达到以下能力：

* 能从零搭建生产级 FastAPI 项目架构。
* 能设计可扩展、可维护的 AI Backend。
* 能实现流式输出（SSE）、实时通信（WebSocket）、后台任务（BackgroundTasks）等 AI 应用核心能力。
* 能为后续 **LLM、RAG、Agent、MCP、AI Companion** 等模块提供稳定、规范的后端服务。

> **说明（Roadmap 调整建议）：** 我建议将 **SQLAlchemy、Alembic、Pydantic Settings、RBAC** 等内容保留在 FastAPI 阶段学习，而把 **PostgreSQL、Redis、Kafka、对象存储** 的底层原理和高级使用放到后面的独立章节深入学习。这样学习顺序更符合真实开发流程：**先学如何在 FastAPI 中使用它们，再深入掌握它们本身。**
