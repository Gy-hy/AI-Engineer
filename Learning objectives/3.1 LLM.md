# LLM 综合毕业项目（★★★★★）

> **LLM Platform**

## 功能要求

* Prompt Playground
* Prompt Version 管理
* Structured Output（Pydantic）
* Function Calling
* Tool Calling
* SSE Streaming
* Long-term Memory
* Context Management

* Latency 监控
* 多模型路由（GPT、Claude、Gemini、DeepSeek、Qwen）

## 毕业标准（★★★★★）

完成该项目后，你应达到以下能力：

* 能设计高质量 Prompt，并构建稳定的结构化输出。
* 能开发支持 Function Calling、Tool Calling、Streaming、Memory 的 AI 应用。
* 能从成本、延迟、上下文管理等角度优化 LLM 系统。
* 能实现企业级多模型路由，为后续 **RAG、Agent、MCP、AI Companion** 提供统一的 LLM 能力层。
