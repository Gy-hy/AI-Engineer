# 4.4 Monitoring（★★★★★）

> **目标：掌握 AI 基础设施的监控、追踪、告警和故障定位能力，能够持续观察模型服务、应用服务和 AI 链路的运行状态。**

---

# 1. Monitoring 基础（★★★★★）

## 必学内容

理解：

* Metrics
* Logs
* Traces
* Dashboard
* Alert

理解：

为什么 AI 系统的可观测性比传统 Web 系统更复杂。

---

## 必做项目

为现有服务整理：

监控指标清单。

区分：

* 系统指标
* 业务指标
* AI 指标

---

# 2. Prometheus（★★★★★）

## 必学内容

掌握：

* Exporter
* Pull Model
* Time Series
* Query
* Alert Rule

理解：

Prometheus 为什么是基础设施监控核心。

---

## 必做项目

为 FastAPI 或 Gateway：

暴露 Prometheus Metrics。

---

# 3. Grafana（★★★★★）

## 必学内容

掌握：

* Dashboard
* Panel
* Variable
* Alert

理解：

为什么监控必须具备可视化能力。

---

## 必做项目

搭建：

Grafana Dashboard。

展示：

* QPS
* Latency
* Error Rate
* Resource Usage

---

# 4. OpenTelemetry（★★★★★）

## 必学内容

掌握：

* Trace
* Span
* Context Propagation
* Instrumentation

理解：

为什么分布式 AI 请求必须依赖 Trace 才能定位问题。

---

## 必做项目

为：

API → Gateway → LLM / RAG / Agent

接入：

OpenTelemetry Trace。

---

# 5. Langfuse（★★★★★）

## 必学内容

掌握：

* Prompt Trace
* Generation Trace
* Tool Trace
* Cost Tracking
* Evaluation Integration

理解：

Langfuse 在 AI Observability 中的定位。

---

## 必做项目

接入：

Langfuse。

完整记录：

Prompt → Retrieval → Tool → Response。

---

# 6. LangSmith（★★★☆☆）

## 必学内容

理解：

* Trace
* Eval
* Dataset

理解：

LangSmith 与 Langfuse 的差异。

---

## 必做项目

调研：

LangSmith 与 Langfuse 的功能对比。

---

# 7. Sentry（★★★★☆）

## 必学内容

掌握：

* Error Tracking
* Exception Context
* Release Tracking

理解：

为什么异常上报不能被 AI Trace 替代。

---

## 必做项目

为应用服务接入：

Sentry。

---

# 8. AI 指标设计（★★★★★）

## 必学内容

掌握：

* Token Usage
* Cost
* Success Rate
* Tool Success Rate
* Retrieval Hit Rate
* Agent Task Success

理解：

传统 CPU / Memory 指标无法回答 AI 系统是否“有用”。

---

## 必做项目

设计并实现：

AI 专用监控指标面板。

---

# 9. 告警与故障处理（★★★★★）

## 必学内容

掌握：

* 阈值告警
* 异常告警
* 降级策略
* 故障复盘

理解：

生产环境中的监控闭环不止是“看见问题”，还包括响应和修复。

---

## 必做项目

建立：

基础告警规则。

至少覆盖：

* 高错误率
* 高延迟
* 推理服务不可用

---

# Monitoring 综合毕业项目（★★★★★）

> **AI Observability Stack**

## 功能要求

* Prometheus 指标采集
* Grafana Dashboard
* OpenTelemetry Trace
* Langfuse AI Trace
* Sentry 异常追踪
* AI 专用指标面板
* 基础告警规则

---

## 毕业标准（★★★★★）

完成该项目后，你应达到以下能力：

* 能区分 Metrics、Logs、Traces 在 AI 系统中的作用。
* 能为 AI Gateway、RAG、Agent、推理服务建立可观测性体系。
* 能从性能、成本、错误、AI 质量四个角度发现并定位问题。

---

| --------------- | ----- | -----: |
| Prometheus      | ⭐⭐⭐⭐⭐ |     精通 |
| Grafana         | ⭐⭐⭐⭐⭐ |     精通 |

| Sentry          | ⭐⭐⭐⭐☆ |     熟练 |
| 告警与故障处理         | ⭐⭐⭐⭐☆ |     熟练 |
| LangSmith       | ⭐⭐⭐☆☆ |     熟悉 |

> **建议：** Monitoring 是 Layer 4 最容易被低估的一节。真正进入生产后，你会发现系统“能跑”根本不够，关键是出问题时能否在几分钟内定位到是哪一层坏了，是模型、网关、检索、工具、还是基础设施本身。
