# 6. AI 场景（★★★★★）

## 必学内容

理解对象存储在 AI 系统中的作用：

存储：

* PDF
* Word
* 图片
* 音频
* 视频
* Embedding 原始文件
* 模型文件
* Agent 生成文件

数据库只保存：

* URL
* Metadata
* 文件状态

---

## 必做项目

实现：

知识库文件系统。

流程：

```text
上传文件
    │
    ▼
MinIO/S3
    │
    ▼
数据库保存 Metadata
    │
    ▼
后台解析
    │
    ▼
RAG
```

# Object Storage 综合毕业项目（★★★★★）

> **AI File Storage Service**

## 功能要求

* Docker 部署 MinIO
* 使用 S3 API 完成上传、下载、删除
* 支持 Presigned URL
* FastAPI 集成对象存储
* PostgreSQL 保存文件元数据
* Docker Compose 一键部署
* 为后续 RAG、Agent、AI Companion 提供统一文件存储服务

---

## 学习优先级（建议）

| 技术                | 优先级   | 必须掌握程度 |
| ----------------- | ----- | -----: |
| S3 API（概念与接口）     | ⭐⭐⭐⭐⭐ |     精通 |
| MinIO             | ⭐⭐⭐⭐⭐ |     精通 |
| 阿里云 OSS / 腾讯云 COS | ⭐⭐⭐☆☆ |     熟悉 |

> **建议：** 不需要分别精通 S3、OSS、COS，它们的核心接口几乎都遵循 **S3 API**。**MinIO + S3 API** 学透之后，迁移到任何云对象存储的成本都很低。
