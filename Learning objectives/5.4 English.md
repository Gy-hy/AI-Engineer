# 5.4 English（★★★★★）

> **目标：建立以英文为主的技术输入能力，能够持续阅读 AI 工程领域的一手资料，而不是依赖二手翻译与碎片化解读。**

---

# 1. 官方文档（★★★★★）

## 必学内容

理解：

* Official Docs 是第一手资料
* 文档更新速度通常快于教程和课程

理解：

为什么高级工程师必须直接读官方文档。

---

## 必做项目

建立：

自己的 AI 官方文档清单。

---

# 2. RFC（★★★★☆）

## 必学内容

理解：

* RFC
* Proposal
* Design Discussion

理解：

为什么很多重要能力在正式发布前就已经出现在 RFC 或设计提案中。

---

## 必做项目

挑选：

一个你关心的技术 RFC。

输出：

中文总结与关键点拆解。

---

# 3. Paper（★★★★☆）

## 必学内容

理解：

* Abstract
* Method
* Experiment
* Limitation

理解：

AI 工程师不需要天天读论文，但必须具备读关键论文的能力。

---

## 必做项目

阅读并总结：

至少 3 篇关键 AI 论文。

---

# 4. GitHub（★★★★★）

## 必学内容

掌握：

* README
* Issue
* PR
* Discussion
* Release Note

理解：

为什么 GitHub 是技术英文阅读的主战场之一。

---

## 必做项目

每周固定阅读：

至少一个 AI 项目的更新记录。

---

# 5. Blog（★★★★★）

## 必学内容

理解：

* Engineering Blog
* Research Blog
* Product Blog

理解：

优秀技术博客常常是最容易吸收的一手工程经验。

---

## 必做项目

整理：

一份值得长期追踪的 AI / Infra 博客清单。

---

# 6. 术语体系（★★★★★）

## 必学内容

掌握：

* Prompt
* Grounding
* Retrieval
* Throughput
* Latency
* Fallback
* Observability
* Routing

理解：

很多人不是英语差，而是技术术语体系不完整。

---

## 必做项目

建立：

自己的 AI 英文术语表。

---

# 7. 阅读速度与筛选（★★★★★）

## 必学内容

掌握：

* 快速浏览
* 关键信息定位
* 判断是否值得深读
* 做阅读摘录

理解：

技术英文阅读的关键不是逐字翻译，而是快速获取有效信息。

---

## 必做项目

建立：

个人英文阅读工作流。

---

# 8. 输出反哺（★★★★★）

## 必学内容

掌握：

* 英文资料中文整理
* 英文术语解释
* 英文原文摘录

理解：

只有做输出，输入能力才会稳定沉淀下来。

---

## 必做项目

每月至少完成：

1 篇英文技术资料精读总结。

---

# English 综合毕业项目（★★★★★）

> **AI English Reading System**

## 功能要求

* 建立英文资料来源清单
* 建立技术术语表
* 固定阅读官方文档 / GitHub / Blog
* 输出多篇精读总结
* 形成长期可执行的阅读习惯

---

## 毕业标准（★★★★★）

完成该项目后，你应达到以下能力：

* 能直接阅读 AI 工程相关英文资料，而不是依赖二手内容。
* 能快速定位官方文档、Issue、Blog、Paper 中的关键信息。
* 能把英文输入转化为自己的长期知识资产。

---

## **学习优先级（建议）**

| 技术              | 优先级   | 必须掌握程度 |
| --------------- | ----- | -----: |
| 官方文档            | ⭐⭐⭐⭐⭐ |     精通 |
| GitHub          | ⭐⭐⭐⭐⭐ |     精通 |
| Blog            | ⭐⭐⭐⭐⭐ |     精通 |
| 术语体系            | ⭐⭐⭐⭐⭐ |     精通 |
| 阅读速度与筛选         | ⭐⭐⭐⭐⭐ |     精通 |
| 输出反哺            | ⭐⭐⭐⭐☆ |     熟练 |
| RFC             | ⭐⭐⭐☆☆ |     熟悉 |
| Paper           | ⭐⭐⭐☆☆ |     熟悉 |

> **建议：** 英文不是单独的一门课，而是你整个 AI 职业发展的输入管道。真正的差距通常不是“谁更会背知识”，而是谁能更快接触到一手信息、理解它、消化它、再转化成自己的判断。
