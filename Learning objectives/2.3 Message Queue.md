## **学习优先级（建议）**

| 技术           | 优先级   |  必须掌握程度 |
| ------------ | ----- | ------: |
| Celery       | ⭐⭐⭐⭐⭐ |      精通 |
| Redis Stream | ⭐⭐⭐⭐⭐ |      熟练 |
| RabbitMQ     | ⭐⭐⭐⭐☆ |      熟悉 |
| Kafka        | ⭐⭐⭐⭐☆ | 熟悉原理与实践 |

> **建议调整 Roadmap：** 对于 AI 应用开发者而言，**Celery + Redis** 是最值得优先掌握的组合，它覆盖了绝大多数异步任务场景（OCR、Embedding、RAG、Agent）。**Kafka** 更偏向大规模数据平台、实时流处理和事件驱动架构，通常在大型互联网或数据平台中使用；**RabbitMQ** 适用于需要可靠消息投递和复杂路由的业务系统。先精通 **Celery + Redis Stream**，再学习 Kafka 和 RabbitMQ，会更符合 AI System Engineer 的成长路径。
