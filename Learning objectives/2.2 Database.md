## **学习优先级（建议）**

| 技术             | 优先级   |   必须掌握程度 |
| -------------- | ----- | -------: |
| SQL            | ⭐⭐⭐⭐⭐ |       精通 |
| PostgreSQL     | ⭐⭐⭐⭐⭐ |       精通 |
| Redis          | ⭐⭐⭐⭐⭐ |       精通 |
| SQLAlchemy 2.0 | ⭐⭐⭐⭐⭐ |       精通 |
| SQLite         | ⭐⭐⭐⭐☆ |       熟练 |
| MongoDB        | ⭐⭐⭐☆☆ | 熟悉（按需深入） |

> **建议调整 Roadmap：** 在当前 AI 工程实践中，**PostgreSQL + Redis** 已经覆盖了绝大多数 AI 应用场景（聊天、用户、RAG 元数据、Agent 状态等）。**SQLite** 主要用于本地应用或 Demo，**MongoDB** 更多是特定场景（日志、文档型数据）使用，因此学习时应把重心放在 **SQL、PostgreSQL、Redis** 上，把 SQLite 和 MongoDB 作为补充能力。
