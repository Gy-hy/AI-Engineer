# 4.1 GPU（★★★★★）

> **目标：理解 GPU 与大模型推理的底层资源约束，能够判断显存、并行、量化、缓存等关键因素对 AI 系统性能和成本的影响。**

---

# 2. 显存（VRAM）（★★★★★）

# GPU 综合毕业项目（★★★★★）

> **LLM GPU Deployment Study**

## 功能要求

* 至少评估 2 种模型规模
* 至少评估 2 种量化方案
* 统计显存、吞吐、延迟、成本
* 输出 GPU 选型建议
* 总结不同部署策略的适用场景

---

## 毕业标准（★★★★★）

完成该项目后，你应达到以下能力：

* 能解释 GPU、显存、Batch、KV Cache、量化对推理系统的实际影响。
* 能根据模型规模、并发需求和成本约束，设计合理的 GPU 部署方案。
* 能与推理框架、平台工程、产品需求结合，而不是孤立看待硬件问题。
